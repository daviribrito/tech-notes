# 05 · Redes de computadores e comunicação

> Como os dados viajam entre máquinas: TCP/IP, DNS, HTTP, TLS, proxies e balanceamento.

**Objetivo:** Diagnosticar problemas de conexão, latência e configuração entre cliente, servidores e serviços.

**Nível recomendado:** N1–N3 · **Prioridade:** Essencial · **Progresso:** `░░░░░░░░░░` 0%

## Critérios de conclusão

- [ ] Descrever o caminho de uma requisição HTTPS do DNS até a resposta.
- [ ] Explicar as diferenças entre TCP e UDP e entre HTTP/1.1, HTTP/2 e HTTP/3.
- [ ] Configurar um reverse proxy com TLS e balanceamento.
